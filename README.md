# 已读之后 ·《沟通的艺术》第三组汇报

37 页离线演示，主题是**现代职场中的跨世代沟通障碍**：同一条消息，为什么会让双方都觉得没有被理解。

页面为纯静态 HTML（图片、字体全部内嵌），不依赖网络，双击 `index.html` 即可离线播放；也支持双屏演讲者控制台。

## 说明

- 演讲者控制台「本地视频」面板内置两个一键载入按钮：**载入结尾视频**（Leah Georges 片段，附中文字幕）与**载入第二部分视频**（李宗恒《准时下班！》，片内自带字幕，载入时会自动清空上一段视频的字幕）。按钮从 `closing-video/`、`part2-video/` 在线读取视频，需通过 GitHub Pages 使用；离线双击 HTML 时请改用「选择视频」。
- 组员署名共 10 位，第二部分署名已更正为「俞林君」。
- 第 6 页的微笑表情使用微信「微笑」官方表情的高清放大版，仅作符号示意。
- 摄影素材来自 Pexels，作者与原始链接见 `已读之后/图片来源.html`。
- 表情贴纸仅作视觉玩梗，不参与论证，也不代表研究或案例材料。
