主题首页（index.html）：主题简介、十位组员分工、38页缩略图；可从任意一页开始，提供“双屏演讲”和“单屏播放”两个入口。缩略图由当前演示逐页生成，与正式画面一致。
演讲者控制台（presenter.html，或首页、演示画面中的P键）：为38页分别整理关键词、三步讲述框架和衔接句；显示本部分概要、当前画面预览、全组与本部分进度，并加入翻页、计时、黑屏和视频控制。双屏联动使用同源窗口消息，不依赖网络或插件；“结束放映”会关闭放映窗口，或把由演示页打开的控制台关闭并恢复原标签页。
工具栏（本版更新）：改为“靠近唤起”。鼠标进入画面底部约150像素的热区时，底部工具栏浮出；鼠标离开该区域约1秒后淡出，停在工具栏上时保持显示；点击画面任意处也会收起。单屏播放与扩展屏放映窗使用同一规则。扩展屏放映窗只保留上一步、页码、下一步、章节目录、全屏五个公开控件，练习提示、文字编辑、双屏按钮和帮助仍只在电脑上的演讲者控制台使用；放映窗首次加载不会闪出工具栏。工具栏隐藏时不再拦截鼠标点击，也不会误触底部按钮。
扩展屏：用 Window Management API 读取显示器，由放映窗口自行移动位置并进入全屏，兼容 macOS 与 Windows 的 Chrome / Edge。切换显示器或在控制台点“放映屏全屏”会先移动再全屏；浏览器要求每个放映窗口首次手动确认一次全屏（点控制台“放映屏全屏”，或在放映窗口按任意键/点一下）。全屏请求会显式传入所选显示器（requestFullscreen 的 screen 选项），避免 macOS 把全屏 Space 建在错误屏幕；如仍错误，再点一次“放映屏全屏”会退出并重新定位。之后切换与全屏可自动完成。未授权窗口管理或使用其他浏览器时，可手动把放映窗口拖到扩展屏再全屏。另提供“铺满屏幕”备用模式：不调用系统全屏，直接把放映窗口铺满所选显示器（会保留一条浏览器标题栏/标签条）；用于规避 Chrome 156 + macOS 27 上“全屏状态生效但窗口不放大”的已知问题，全屏失败时会自动启用。
