双屏放映（推荐）：
首页选择“双屏演讲”，先点“识别扩展屏”并允许浏览器识别显示器，再选放映屏；点“开始放映”或任意缩略图后，放映窗口会自动移到所选显示器。
首次进入时浏览器可能要求确认一次全屏：点控制台“放映屏全屏”，或在放映窗口按任意键、点一下画面。全屏会明确指定所选的显示器；如仍出现在错误屏幕上，再点一次“放映屏全屏”即可校正。确认后切换显示器、再次全屏会自动完成。
控制台显示：本部分进度、当前画面预览、当前页关键词、三步讲述框架、衔接句、本部分概要、全组进度，以及翻页、计时、黑屏和视频控制。
“打开放映屏”可重新连接；浏览器拦截弹窗时，允许本页打开一个独立窗口即可。
“结束放映”会关闭放映窗口；从 slides.html 按 P 打开的控制台，结束时会关闭控制台，并把原演示恢复为可独立翻页。
自动放置需要 Chrome / Edge 的窗口管理权限；未授权或使用其他浏览器时，把放映窗口手动拖到扩展屏，再点窗口上的“全屏放映”。
如果全屏仍跳到内建屏：先点一下放映窗口，再按 Ctrl+⌘+F（macOS）或 F11（Windows）用浏览器自身的全屏，这种方式一定使用窗口当前所在的显示器。
已知问题：Chrome 156 与 macOS 27（Golden Gate）组合下，系统全屏可能只改变状态、不真正放大窗口，其他网页也一样。本演示准备了“铺满屏幕”备用按钮：把放映窗口铺满所选显示器（会保留一条浏览器标题栏/标签条），不依赖系统全屏；全屏按钮无效时会自动使用它。需要完全无边框的全屏，请在 Chrome 修复前使用 Safari，或把 macOS 27 回退/更新到修复版本。
macOS 请在“系统设置 → 显示器”使用“扩展显示”；Windows 按 Win+P 选择“扩展”，并把放映窗口放到第二块屏。
视频：在控制台选择本地视频，放映窗口负责播放；播放、暂停、进度和返回幻灯片都从控制台操作。选片和字幕只在本次会话有效。

工具栏（单屏播放与扩展屏放映规则相同）：
鼠标移到画面底部边缘附近（约下方150像素内），底部工具栏自动浮出；移开该区域约一秒后淡出，停在工具栏上时保持显示。单屏播放显示完整工具栏；扩展屏放映窗只保留上一步、页码、下一步、章节目录、全屏这几个公开控件，练习提示、文字编辑、双屏按钮和帮助仍只在电脑上的演讲者控制台里使用。放映窗初次加载不会闪出工具栏。

实名署名：
封面列出十位组员；每一部分首页标注该部分汇报人。首页“编辑信息”可临时补充或修改姓名，修改只保存在当前浏览器，不写回HTML；重新拷贝文件夹后恢复默认名单。

操作（演示画面）：
→ / 空格 / PageDown：逐步揭示，再进入下一画面。
← / PageUp：撤回当前揭示，再回到上一画面。
鼠标：移到画面底部附近显示工具栏；移开后自动隐藏。
Esc：关闭面板；正式画面中打开章节目录。
Home：回到开头。End：进入最后陈词，不进入参考页。
F：全屏。B：黑屏；Esc恢复。
N：练习面板，包含当前提示和本部分原始讲稿。正式投影前务必关闭。
V：选择本地视频。选片后需手动播放，可加入VTT字幕。关闭面板会暂停。
E：文字编辑。左上角悬停也可找到。Esc完成，Ctrl/⌘+S导出修改版HTML。
编辑缓存只属于当前浏览器和文件；完整演示与个人演示分别保存。若两份都需要改字，应分别修改并导出。
视频选择只在本次会话有效。最终视频尚未提供，因此当前没有预设播放片段；选择电脑文件后可离线播放。
只需播放时，字体、样式和脚本均已嵌入HTML，不依赖网络或安装。
整个文件夹复制到另一台电脑即可使用。建议先用Chrome或Edge测试全屏和视频。
